# 📰 Football Headlines Auto Scraper

This Python project automatically scrapes the latest football headlines from **BBC Sport** and saves them to a text file.  
It can also send hourly email updates using an automated script.

---

## ⚙️ Features
- Scrapes live football headlines from BBC
- Saves them to `news.txt`
- Sends automatic email updates every hour

---

## 🧠 Technologies Used
- Python 3
- BeautifulSoup (for web scraping)
- smtplib (for email automation)
- Termux (Linux environment on Android)

---

## 🚀 How to Run
```bash
python scraper.py
